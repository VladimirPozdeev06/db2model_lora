# Leaderboard — DB2Model

Единая сравнительная таблица (DoD недель 5–6). Все числа — на одном split:
**91 вопрос `bird_large`** по трём базам `financial / toxicology / codebase_community`,
target — **Qwen2.5-Coder-3B-Instruct** (4-bit), один исполнитель SQL, один парсер.

Оси сравнения из плана: **EX** (точность), **VES** (эффективность корректных запросов),
**prompt-токены/запрос** (бюджет контекста — ключевая метрика задачи).

## Канонический замер (оценщик напарницы) + ablation учитель/мультизадачи

Все армы, прогнанные через **единый оценщик напарницы** (`evaluate_bird.py` + её
`bird_large_filtered.json`) — чтобы числа были сравнимы между ветками. baseline
консистентен (19.78% в обоих прогонах), значит различия — в lora, не в замере.

| Арм (lora, знание в весах) | Учитель / данные | EX | VES | codebase / tox / fin |
|---|---|---|---|---|
| zeroshot (контроль) | — | 4.40% | 3.85 | 14.8 / 0 / 0 |
| baseline (наш) | схема в контексте | 19.78% | — | 25.9 / 20.0 / 13.8 |
| baseline (напарницы) | её light-RAG инструмент | 24.18% | 20.60 | — |
| old_lora | Qwen-7B, 1171, sql-only (1 сид) | 27.47% | 21.15 | 29.6 / 34.3 / 17.2 |
| new_lora | Qwen-27B, 2699, **+мультизадачи** (1 сид) | 25.27% | 21.15 | 22.2 / 34.3 / 17.2 |
| qwen27b_sql_only **3B** | Qwen-27B данные, target 3B (3 сида) | 29.30% ± 1.37 | 25.4 | fin 20.7 |
| baseline **7B** | схема в контексте, target 7B | 28.57% | 26.4 | 40.7 / 28.6 / 17.2 |
| **qwen27b_sql_only 7B** | **Qwen-27B данные, target 7B (3 сида)** | **38.09% ± 1.37** | **29.1** | fin 34.5 |

**Лучший результат — `qwen27b_sql_only` на target 7B = 38.09% ± 1.37** (сиды 0/1/2:
38.46 / 39.56 / 36.26), плановая основная модель. Знание в весах против контекста:
**+9.5 п.п. над 7B-baseline (28.57)** при контексте в 3.2× меньше. Выше 3B (29.30 ± 1.37,
+8.8) и baseline напарницы (24.18, +13.9). Тезис держится на **обоих** размерах, оба
сид-подтверждены; разрыв ≫ σ = 1.37.

Одиночный 7B-прогон давал 36.26% — это оказался **низкий** сид (в этот раз единичный
прогон был пессимистичен), честное среднее выше.

**3B-победитель — `qwen27b_sql_only` = 29.30% ± 1.37** (сиды 30.77/27.47/29.67):
**+9.5 п.п. над нашим baseline (19.78)**, ≫ σ; выше baseline напарницы (24.18) на +5.1.

⚠️ **Поправка на сид.** Одиночный прогон этой же конфигурации дал 32.97% — это
**высокий сид** (выше всего диапазона 3 сидов). Как и seed42 раньше, единичный
прогон оптимистичен; честное число — среднее 29.30 ± 1.37.

**Ablation (с поправкой на сид — деталь для защиты):**
- **Мультизадачность — вредна:** new_lora 25.27 (1 сид) ниже всего диапазона
  победителя (27.47–30.77) → **выключаем**. Сильнее всего бьёт по `codebase`.
- **Учитель 7B→27B:** old_lora 27.47 (1 сид) попадает **внутрь** ±σ победителя
  (29.30 ± 1.37) → на этом объёме эффект учителя **в пределах шума, не доказан
  строго** (прежние «+5.5» держались на высоком сиде 32.97). Нужны сиды и на old_lora.

Артефакты: `adapters/qwen27b_sqlonly1096/` (победитель); предсказания —
`results/query_results_qwen27b_sqlonly_seed{0,1,2}.json` и `..._{sqlonly,multitask}_*.json`.
